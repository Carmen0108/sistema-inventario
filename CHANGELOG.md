# Historial de versiones

## v1.0.0
- Primera versión del Sistema de Inventario.
- Incorporación de la funcionalidad Producto (código, nombre, precio, existencia).
- Programa de consola para registrar y mostrar productos.
- Implementación de pruebas automatizadas (CP01–CP07) con unittest.
- Workflows de GitHub Actions: build, test y release.

## v1.0.1 (no publicada)
- Versión con error intencional en `obtener_precio()`; las pruebas fallaron y el workflow no publicó la versión.

## v1.0.2
- Corrección del error detectado durante las pruebas.
- Validación satisfactoria de la funcionalidad Producto.
